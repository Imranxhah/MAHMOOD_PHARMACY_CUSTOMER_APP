# Cover artwork

`cover.jpg` is original illustrative artwork created for this repository using the built-in image generation tool. It is not an application screenshot or evidence of product functionality.

## Generation prompt

Use case: stylized-concept. Create an elegant wide 3:1 GitHub repository cover illustration for a pharmacy software project. Exact title text: "MAHMOOD PHARMACY". Small subtitle: "Flutter app + Django API". Deep navy background with a restrained teal and mint palette, precise editorial typography on the left, refined isometric illustration on the right of a medicine package, an abstract mobile device, and connected server modules. High quality restrained 3D paper and matte material aesthetic, generous whitespace, polished software portfolio branding. Abstract device has no realistic UI, no metrics, no maps. No claim of medical certification, no red cross logo, no watermark. Render as one finished wide cover image.

## Maintenance

Retain the descriptive alt text when embedding the cover. Use actual captures for any future screenshot gallery and label the platform/build represented.
