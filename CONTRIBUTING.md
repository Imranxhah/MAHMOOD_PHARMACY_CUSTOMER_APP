# Contributing

Thanks for helping improve this project. Start with the [README](README.md) and its setup guide.

## Report an issue

Describe the expected behavior, actual behavior, and shortest steps to reproduce it. Include your OS, runtime/SDK version, and a redacted error message. Use synthetic data and remove passwords, API keys, access tokens, personal details, and private documents.

## Propose a change

1. Create a focused branch from the default branch.
2. Make the smallest coherent change and update the relevant documentation.
3. Run checks appropriate to the change. Explain any existing failures or checks you could not run.
4. Open a pull request describing the problem, behavior after the change, and verification.

For documentation, check relative links, commands, configuration names, and image alt text. For code, include regression coverage when it meaningfully protects behavior. Do not make live API calls or use production data in tests.

## Visual assets

Use real app captures for screenshots and identify illustrative artwork as such. Keep assets in `docs/assets/`, use descriptive names, and avoid private information. Do not imply features or validation that the implementation does not provide.

## Sensitive reports

Do not post credentials or personal information in a public issue. Contact the maintainer privately through a contact channel they have published; this repository does not define a dedicated security-response process.
